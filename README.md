# Документация codef

codef — настольное приложение для чата с ИИ и работы над проектами. Модель можно запустить на своём компьютере или подключить через облачный API.

## Начало работы

1. [Скачай codef](https://codef.su/ru/download/) для macOS, Windows или Linux.
2. Для локальной модели открой «Модели и загрузки». Для облачной — «Настройки → Модели и API» и укажи данные своего провайдера.
3. В режиме «Чат» можно задавать вопросы и прикреплять файлы. В режиме «Агент» выбери папку проекта, если нужна работа с его файлами.
